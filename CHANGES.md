# Eventer App — журнал работы

## Правила веток
- **main** — рабочая версия. Публикуется на https://alembot.github.io/eventer-app-k/. Должна всегда работать.
- **claude** — ветка Claude. **gpt** — ветка ChatGPT.
- Перед началом работы: забрать свежий `main` в свою ветку (`git merge origin/main`).
- Закончил кусок → слил свою ветку в `main` и записал сюда, что сделано и что осталось.
- Не держать изменения отдельно дольше одного рабочего дня.

## Данные
- База: Eventer Data Base (Supabase `hgzxowfegmvxqtryphbd`).
- Публично доступны только две функции (только поля для витрины, без телефонов):
  - `POST /rest/v1/rpc/pub_brief_config` `{"p_type":"Свадьба"}` — 17 специалистов, вопросы, бюджеты.
  - `POST /rest/v1/rpc/pub_brief_match` `{"a":{"city","guests","needs":[{key,roles,like,unit,budget_max}]}}` — подбор, до 5 карточек на специалиста.
- Ключ — публичный (publishable), в `index.html`. Секретные ключи в код не класть.
- eventchat.kz (прод) не трогать без отдельного решения Кайрата.

## Утверждённые решения по структуре (16.10.2026, Кайрат)
- Вход: «Частное событие» / «Для бизнеса». Частное — Свадьба, Детский праздник, Юбилей, Вечеринка. Бизнес — Деловое, Корпоративное, Концерт и культурное, Общественное.
- Нижнее меню частного заказчика: Главная · Каталог · Ассистент (в центре) · Журнал · Мой план.
- Центральная кнопка «Ассистент» открывает только диалог с ассистентом (пока заглушка «скоро»), на планировщик не ведёт.
- Блок на главной: надпись «Свадебный планировщик», заголовок «Не знаете, с чего начать?», подзаголовок «Eventer рассчитает бюджет и подберёт исполнителей», красная кнопка «Начать». Слово «бриф» заказчику не показываем.
- «Профи» в меню заказчика → «Каталог». «Eventer для профи» — вход для исполнителей в профиле.
- «Мой план»: мои события, бюджет (заложено / договорились / внесено / осталось), команда со статусами, чек-лист со сроками, заявки и ответы, сохранённое (сердечко), гости, «Поделиться с семьёй».
- Профиль — только аккаунт: Поддержка, Настройки, Eventer для профи, Бизнес-аккаунт, Подсказать место, О сервисе.
- Бизнес: меню Главная · Проекты · Ассистент · Каталог · План. Профи: Главная · Заявки · Ассистент · Календарь · Моя карточка.

## API Eventer Data Base для приложения (публичный ключ, только поля витрины)
Базовый адрес: `https://hgzxowfegmvxqtryphbd.supabase.co/rest/v1/rpc/<функция>`, метод POST, заголовки `apikey: <publishable key из index.html>`, `Content-Type: application/json`.

| Функция | Тело запроса | Ответ |
|---|---|---|
| `pub_brief_config` | `{"p_type":"Свадьба"}` | 17 специалистов: code, name, roles, like, unit, budget, questions |
| `pub_brief_match` | `{"a":{"city","guests","needs":[{key,roles,like,unit,budget_max}]}}` | по каждой позиции: total, in_city, matched, rows (до 5 карточек: id, name, sub, cap, price, price_unit, verified …) |
| `pub_price_tiers` | `{"p_city":"Алматы"}` | `{code:[{tier 0..2, min, max, unit, source, samples}]}`. `source="estimate"` — примерные цены, `"market"` — собраны роботом, `"eventer"` — по реальным ценам базы |
| `pub_vendor_card` | `{"p_id":"<uuid>"}` | подробная карточка: описание, вместимость, цены, языки, типы событий, Instagram, сайт, verified, claimed. Телефона и почты нет |
| `pub_vendor_search` | `{"q":"текст, ник или телефон"}` | до 10 карточек для «Вы уже есть в Eventer?»: id, name, role, category, city, instagram, phone_hint («•• 48»), claimed. Минимум 3 символа |
| `pub_vendor_apply` | `{"a":{participant_id?, name, city, category, phone, …остальные поля анкеты}}` | `{id, kind: claim/new, status: pending}`. Обязательны name, city, category, phone. Не больше 5 заявок с одного номера в сутки |
| `pub_vendor_application_status` | `{"p_id":"<id заявки>"}` | `{status: pending/needs_info/verified/rejected, note}` |

Правила: в интерфейсе показывать только то, что вернула функция; если поля нет — «пока нет данных». Код в WhatsApp пока не подключён: в рабочей версии заявка уходит со статусом «Проверяем», подтверждение номера добавим отдельно.
